# Project Status

## Current Restoration

The build reproduces the surviving game binary byte for byte. VICE checks confirm that the title screen renders and that the game reaches gameplay on a 16 KB PAL C16, using scripted fire input. Seven regression tests pass. Manual input testing and a full play-through are still to do.

[Restoration Status](docs/RESTORATION_STATUS.md) has the source provenance, the reference graphics dependency, the verification evidence, and the research still open. [Quick Start](QUICKSTART.md) covers building and running.

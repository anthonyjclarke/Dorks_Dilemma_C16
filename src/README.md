# Earlier Converted Source

## Historical Role

The assembly files in this folder are earlier consolidated, converted, or reconstructed versions, kept for comparison. They are not inputs to the current restoration build, and they have known conversion defects.

The current pipeline follows the preserved C16 disk image and four explicit archive modules. Run `./build.sh` from the project root, then look at `build/recovered-c16.s` and `build/recovery-manifest.json` for the generated assembly and where it came from.

See [Source to VICE](../docs/SOURCE_TO_VICE.md) and [Restoration Status](../docs/RESTORATION_STATUS.md).
